## Diagnóstico de problemas de negócio
- Problema de oferta: leads chegam mas não compram → Grand Slam Offer
- Problema de leads: poucos leads qualificados → Core 4 (leads pagos, orgânicos, indicações, parcerias)
- Problema de precificação: dificuldade de justificar preço → Value Equation
- Problema de vendas: leads não convertem → CLOSER framework
- Problema de retenção: alto churn → Retention frameworks
- Problema de escala: preso em platô → Scaling frameworks
- Problema de modelo: margens baixas → Business model redesign

## Value Equation
Valor = (Resultado Desejado × Probabilidade Percebida) / (Delay de Tempo × Esforço/Sacrifício)
Para aumentar valor: aumentar resultado + aumentar probabilidade + diminuir tempo + diminuir esforço.

## CLOSER para vendas
Clarify → Label → Overview → Sell the Vacation → Explain Away Objections → Reinforce
